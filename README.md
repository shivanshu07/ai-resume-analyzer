# Resume Analyzer

An AI-powered Resume Analyzer built with Python, FastAPI, Streamlit, Sentence Transformers, FAISS, and Large Language Models.

## Features (Planned)

- PDF Resume Parsing
- Job Description Parsing
- Text Cleaning
- Semantic Embeddings
- Resume–JD Similarity
- ATS-style Match Score
- AI-Powered Resume Feedback
- Evaluation with DeepEval

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app/main.py
```
